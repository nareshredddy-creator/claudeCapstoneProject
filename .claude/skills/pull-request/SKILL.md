# Skill: Pull Request Preparation (Stage 8)

## Purpose
Assemble the complete PR from all pipeline artifacts, apply AI-disclosure requirements, and
create the PR on GitHub — but only after explicit human approval.

## When to invoke
When the `sdlc-orchestrator` delegates Stage 8 to the `pr-agent`.

## Instructions

### Prerequisites
- Stages 1–7 all approved with evidence.
- Feature branch is checked out and has commits.
- `sdlc-config.json` read for AI-disclosure values and GitHub repo.

### Step 1 — Verify commits exist and have trailers
```bash
git log main...<branch> --oneline
git log main...<branch> --format="%H %s%n%b"
```

Every commit must end with:
```
Co-Authored-By: Claude SDLC Pipeline <noreply@anthropic.com>
```

List any commits missing the trailer. The human must fix them before the PR is created.

### Step 2 — Assemble pr-summary.md
Synthesize all 7 artifacts into `pr-summary.md`. Include:
- PR title: `[AI-Generated] <KEY>: <Summary>`
- Target: `main ← feature/<KEY>`
- What the PR does (from requirements)
- Key decisions (from architecture and implementation notes)
- Code review findings and their resolutions
- Test evidence (exact counts from verification report)
- AC checklist
- Reviewer checklist
- AI-disclosure paragraph (exact text from `sdlc-config.json → pullRequest.aiGenerated.bodyDisclosure`)

### Step 3 — Present and stop for approval
Show `pr-summary.md`. Present the Final Report. Request Stage 8 approval.

**Do not create the PR until the human explicitly approves.**

### Step 4 — Ensure the `ai-generated` label exists
```bash
gh label list --repo nareshredddy-creator/claudeCapstoneProject --json name \
  | grep -q '"ai-generated"' \
  || gh label create "ai-generated" \
       --repo nareshredddy-creator/claudeCapstoneProject \
       --color "8B00FF" \
       --description "PR generated by AI-assisted SDLC pipeline"
```
Report whether the label already existed or was just created.

### Step 5 — Create the PR (after approval only)
```bash
gh pr create \
  --repo nareshredddy-creator/claudeCapstoneProject \
  --base main \
  --head <branch> \
  --title "[AI-Generated] <KEY>: <Summary>" \
  --body "$(cat <artifactDir>/pr-summary.md)" \
  --label "ai-generated"
```

### Step 5 — Verify all four AI-disclosure elements
```bash
gh pr view <number> --json number,title,labels,body
```

Checklist — all four must be confirmed:
- [ ] Title begins with `[AI-Generated]`
- [ ] Label `ai-generated` is applied
- [ ] Body contains the disclosure paragraph from `sdlc-config.json`
- [ ] At least one commit has the `Co-Authored-By` trailer

If any element is missing, correct it (e.g., `gh pr edit`) and re-verify.

### Step 6 — Report completion
Report the PR URL. State clearly: *"The pipeline is complete. The PR is open and awaiting
human review. Agents must not merge this PR."*

Update `workflow-session.json → runStatus` to `"complete"` and record the PR number and URL.

### NEVER do these
- `gh pr merge` — agents never merge PRs
- `git push --force`
- Create the PR without the `[AI-Generated]` prefix
- Omit the `ai-generated` label
- Omit the body disclosure
